# Vibe Patent for Cursor

Turn your code into a U.S. provisional patent application, and request review and filing by a registered patent attorney.

This plugin connects Cursor to the Vibe Patent MCP server and adds a `code-to-patent` skill. Cursor's agent reads your repository on your machine and sends Vibe Patent the assembled software specification text, not the repository.

## Setup

1. Install the plugin in Cursor.
2. In Cursor Settings, under Tools & MCP, click Connect next to `vibe-patent`.
3. Sign in to Vibe Patent in the browser and approve access. You need a free Vibe Patent account.

## First prompt

Open your project and ask the agent, in Agent mode:

> Prepare a patent disclosure from this repo with Vibe Patent.
